# SIGEH 1.3.0

## Novedades

- Recomendaciones de medicamentos, laboratorios e imágenes aprendidas de recibos generados, según los dos primeros diagnósticos y la especialidad. Son sugerencias seleccionables; nunca se agregan solas. Administración puede configurar diagnósticos y excepciones.
- En el catálogo, el control junto al buscador permite ajustar la cantidad; se elimina el ordenamiento por nombre o precio.
- Se corrige la importación del listado de medicamentos desde documentos Word.
- Se incluye la migración aditiva del esquema privado para recomendaciones. La aplicación la prepara al conectarse; no modifica datos históricos ni importes facturados.

## Actualización

La instalación conserva configuración, logo, nombre del hospital, horario y usuarios durante la actualización.
