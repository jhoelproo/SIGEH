# SIGEH 1.3.8

- **Reporte estadístico de Admisión** reorganizado para pantallas pequeñas y los temas claro y oscuro. Los filtros se pueden plegar para ampliar los resultados.
- Navegación al **turno anterior y siguiente** desde el reporte. Limpiar los filtros conserva el turno histórico seleccionado.
- Selección rápida de todas las ARS visibles y limpieza de la selección. Los cambios de ARS, especialidad y cobertura reutilizan los datos cargados; **Generar reporte** consulta datos actualizados.
- **Vistas guardadas** por usuario en cada computadora para recuperar combinaciones de filtros.
- **Pacientes y facturación** muestra los recibos vinculados, su estado y los datos que requieren revisión. Permite abrir el recibo existente o corregir la atención con los permisos correspondientes.
- **Comparar turnos** aplica los mismos filtros a ambos turnos y muestra cantidades, diferencias y variación porcentual.

Incluye el paquete completo para Windows y una actualización incremental desde 1.3.7. La actualización conserva los datos y la configuración local. Los favoritos de filtros se guardan en cada computadora.
