# SIGEH 1.3.9

Parche de emergencia para el cierre al iniciar sesión cuando SIGEH entra en modo sin conexión. La aplicación recupera los favoritos válidos del catálogo desde el formato guardado en el equipo y abre la ventana principal.

Para actualizar desde la versión 1.3.8, cierre SIGEH y vuelva a abrir `SIGEH.exe` con acceso a GitHub. El lanzador comprueba la actualización antes de mostrar la pantalla de inicio de sesión. Incluye un paquete completo para Windows y una descarga incremental desde 1.3.8.
