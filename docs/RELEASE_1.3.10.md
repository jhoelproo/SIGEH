# SIGEH 1.3.10

- Evita repetir cambios en las tablas operativas de PostgreSQL durante el inicio de sesión y la reconexión cuando el esquema ya está instalado.
- Recupera una copia cifrada de la configuración del lanzador si cambia de carpeta en el mismo perfil de Windows.
- Muestra el estado de conexión y permite volver a consultar los representantes del turno.
- Pide cuatro dígitos como mínimo en el número de autorización de Facturación cuando se introduce uno.
- Agrupa diagnósticos por tipo para las sugerencias y guarda la descripción completa en el recibo.

Para actualizar desde SIGEH 1.3.9, cierre la aplicación y vuelva a abrir SIGEH.exe con acceso a GitHub. La versión incluye el paquete completo de Windows y una descarga incremental desde 1.3.9.
